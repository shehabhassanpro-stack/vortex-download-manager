# ADR-013: اعتماد ترخيص GNU GPL-3.0-or-later مع استراتيجية توافق الإضافات

- **Status:** Accepted
- **Date:** 2026-11-25

## Context
نريد ترخيصاً يحفظ حقوق المؤلف الأصلية وبراءات الاختراع، ويضمن قانونياً أن يظل Vortex وأي نسخة معدّلة منه **مجانيين ومفتوحي المصدر للأبد**، مع مراعاة التوزيع المستقبلي على جميع المنصات بما فيها macOS وSafari في Phase 4.

## Decision Drivers
- Strong Copyleft يمنع الشركات من إغلاق الكود وبيعه.
- توافق كامل مع مكتبات Rust/JS (`Apache-2.0`, `MIT`, `MPL-2.0`).
- خطة قانونية نظيفة لـ macOS وإضافات المتصفحات مستقبلاً.

## Considered Options
1. **`GPL-3.0-or-later` للمحرك والتطبيق المكتبي والـ CLI والـ Bridge**، مع:
   - توزيع macOS عبر حزمة موقّعة وموثّقة من Apple (**Notarized `.dmg` + Homebrew Cask**) خارج Mac App Store (قانوني 100% مع GPLv3 مثل OBS وBlender).
   - ترخيص مزدوج متوافق لمجلد إضافة المتصفح الرقيق `extension/` (`MPL-2.0 OR GPL-3.0-or-later`) بحيث يبقى مفتوح المصدر ومجانياً للأبد، مع إبقاء الباب مفتوحاً قانونياً لتغليف Safari Web Extension إذا لزم الأمر مستقبلاً (كونه يتواصل مع المحرك كعملية منفصلة عبر stdio JSON قياسي).
2. **`MIT` / `Apache-2.0` بالكامل** — يسمح بنسخ تجارية مغلقة المصدر (مرفوض).

## Decision
اعتماد **`GPL-3.0-or-later`** للمشروع، وترخيص مجلد `extension/` بـ `MPL-2.0 OR GPL-3.0-or-later` للتوافق الشامل عبر المتاجر.

## Consequences
- **إيجابيات:** حماية حديدية للمجانية وحقوق المؤلف، مع صفر عوائق قانونية في كل متاجر الإضافات ومنصات التشغيل.
- **سلبيات ومقايضات:** لا يوجد — `MPL-2.0` متوافق رسمياً مع `GPL-3.0-or-later` باتجاه واحد يحمي المحرك بالكامل.
- **التحقق والفرض:** فحص التراخيص الآلي بـ `cargo-deny` في CI.
