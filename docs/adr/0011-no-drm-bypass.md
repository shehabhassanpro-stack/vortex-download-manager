# ADR-011: عدم دعم كسر حماية DRM أو تجاوز CAPTCHA نهائياً

- **Status:** Accepted
- **Date:** 2026-11-25

## Context
بعض منصات البث المدفوعة تحمي محتواها بأنظمة DRM (مثل Widevine وPlayReady وFairPlay) أو بوابات CAPTCHA/مكافحة الروبوتات.

## Decision Drivers
- الامتثال القانوني والأخلاقي (DMCA / قوانين حقوق النشر العالمية).
- حماية سمعة المشروع ومطوّريه وضمان قبول الإضافة والتطبيق في متاجر Chrome/Edge/Firefox وwinget وتوقيع الكود دون حظر.

## Considered Options
1. **رفض صريح ودائم لكسر DRM أو تجاوز CAPTCHA** — دعم HLS/DASH القياسي وAES-128 المفتوح فقط، مع رسالة واضحة (`VTX-SEC-002`) عند اكتشاف DRM.
2. **إضافة أدوات فك DRM** — غير قانوني، ويعرض المشروع للحذف والحظر الفوري من GitHub والمتاجر ومزودي شهادات التوقيع.

## Decision
اعتماد **حظر نهائي وغير قابل للتفاوض** لكسر DRM أو تجاوز CAPTCHA في قلب البرنامج وفي أي Plugin رسمي.

## Consequences
- **إيجابيات:** أمان قانوني كامل، بقاء المشروع في المتاجر الرسمية، وثقة المستخدمين والشركات.
- **سلبيات ومقايضات:** لن يتمكن المستخدم من تحميل المحتوى المحمي بـ DRM (وهو خارج النطاق الصريح في §2.3).
- **التحقق والفرض:** توثيق في `CONTRIBUTING.md` و`Threat-Model.md`، وفحص كشف DRM بكود `VTX-SEC-002` في `vortex-media`.
