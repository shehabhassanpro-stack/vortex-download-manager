# ADR-017: دورة الحياة والتعافي الذاتي والإعدادات الذرية

- **Status:** Accepted
- **Date:** 2026-11-25

## Context
برامج سطح المكتب تتعرض يومياً لإعادة تشغيل Windows، وانقطاع الكهرباء، وتشغيل نسخ متعددة بالخطأ، وتلف ملفات الإعدادات أو قاعدة البيانات.

## Decision Drivers
- عدم تشغيل نسختين متعارضتين من البرنامج على نفس القاعدة والملفات.
- عدم فقدان التقدم عند إغلاق Windows.
- قدرة البرنامج على التعافي ذاتياً دون الحاجة لإعادة تثبيت أو مسح البيانات.

## Considered Options
1. **Single-Instance OS Mutex + Startup Self-Healing (`PRAGMA quick_check` + `.bak` + `.vortex.meta`) + Graceful Shutdown (`WM_QUERYENDSESSION`, ≤ 5s, `wal_checkpoint(TRUNCATE)`) + Atomic Config (`temp→fsync→.bak→rename` + Hot-Reload).**
2. **اعتماد إغلاق عادي بدون معالجة إشارات النظام أو حفظ ذري** — يسبب تلف الإعدادات وفقدان آخر التقدم عند إعادة تشغيل Windows.

## Decision
اعتماد بروتوكول دورة الحياة والتعافي الذاتي الكامل الموصوف في §24 من وثيقة التصميم.

## Consequences
- **إيجابيات:** صمود استثنائي أمام أعطال النظام وانقطاع الكهرباء وتحديثات Windows المفاجئة.
- **سلبيات ومقايضات:** كود إضافي في `vortex-platform` و`vortex-storage` — معزول جيداً خلف Traits.
- **التحقق والفرض:** اختبارات تعافي من قاعدة بيانات تالفة وإعدادات مقطوعة واختبار الإغلاق اللطيف.
